# Baseline implementations

This directory contains the baseline implementations used by the FIPER evaluation.
Each subdirectory retains its own upstream setup and attribution instructions. Large
model checkpoints, knowledge-base binaries, generated outputs, and machine-specific
evaluation caches are intentionally excluded from this source repository.

These implementations originate from their respective baseline projects. Their
upstream licenses and notices apply; the repository-level FIPER license does not
supersede third-party terms.

## Baselines by research question

| Research question | Public-test policy | Compared methods |
|---|---|---|
| RQ1 | Public tests are withheld from every optimization-stage operation | Instruction, ICL, RAG, COT, AutoPatch (C++), FasterPy (Python), and EffiSkill |
| RQ2 | Limited public tests are available | Effi-Learner and SBLLM |

The complete programs generated by all baselines are available in the
[baseline-generated code archive](https://drive.google.com/drive/folders/1dHGtQULOvoOsVrumS_jkhSpkdXWaLeM1?usp=sharing).
Private tests remain evaluation-only in both research questions.
